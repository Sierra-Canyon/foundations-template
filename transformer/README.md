# transformer — A07 and A08

`block.png` (A07) is a photo of your own hand-drawn diagram of one decoder-only transformer
block, with every input and output labelled by tensor shape. Pencil and paper only: no
drawing apps or tablets. A diagram copied from Alammar with the labels retyped is worth
nothing; a rough hand drawing with correct shapes is worth full credit.

`examples/` has two model diagrams. They draw A05's `probe.py`, not the transformer block,
so copy the habits and not the content: a shape on every arrow, letters first with the real
numbers beside them, a note wherever a shape changes, and a column saying what the traced
vector carries at each step.

`attention.md` (A08) is exactly one attention head in about 400 words of plain English,
zero equations, built around one concrete example sentence. The constraint is the
assessment: a formula you can reproduce is not the same as a mechanism you can describe.
