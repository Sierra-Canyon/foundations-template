# transformer — A07 and A08

`block.png` (A07) is your own annotated diagram of one decoder-only transformer block,
with every input and output labelled by tensor shape. A diagram copied from Alammar with
the labels retyped is worth nothing; a rough hand drawing with correct shapes is worth
full credit.

`attention.md` (A08) is exactly one attention head in about 400 words of plain English,
zero equations, built around one concrete example sentence. The constraint is the
assessment: a formula you can reproduce is not the same as a mechanism you can describe.
