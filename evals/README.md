# evals — A11

Labs 1 through 3, your own v2 agent instrumented and emitting a viewable trace, and
router and skill evals running against it.

`judge_labels.json` is committed **before** the judge that scores against it. Commit order
is graded. A judge written first and labels written second is a judge grading its own
homework, and the history is what shows which way round you did it.

`JUDGE_REPORT.md` carries per-class agreement, not one overall number.
